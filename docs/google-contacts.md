# Google Контакты: выбор галочками в сегмент кампании

Окно открывается из трёх мест:

- **Контакты → Google Контакты** — добавить в черновик/кампанию из списка или в новый черновик;
- **мастер кампании, шаг «ЦА» → «Из Google Контактов»** — кампании ещё нет, выбранные
  получают тег сегмента из поля мастера (без привязки к кампании, как при выборе из CRM);
- **кампания → «Аудитория» → «из Google Контактов»** — добрать людей именно в эту кампанию.

Внутри — как в самих Google Контактах: слева ярлыки со счётчиками, справа список с
галочками, телефоном и почтой. Поиск фильтрует по ходу ввода (имя, маркер, телефон,
почта; через запятую — любое из, `ск2025/2026` = `ск2025` или `ск2026`). «Выбрать всех
найденных» отмечает весь отфильтрованный список, за один раз — до 500 человек.
«Обращение в сообщении» берётся из имени Google; если в имени маркер с цифрами — поле
пустое, его надо вписать (без обращения импорт не пройдёт).

Если целевая кампания идёт, окно спросит подтверждение: добавленным начнут писать
по её лимитам. Черновик и пауза — без вопроса. Само окно рассылку не запускает.

Адресная книга читается целиком (`people.connections.list` + `contactGroups.list`) при
открытии окна и по «↻ Обновить»; снимок живёт 30 минут. Фоновой синхронизации и записи
в Google нет. Удаления в Google карточки AXIOM не трогают.

## Подключение Google (один раз, прямо из пульта)

Google пускает возврат после входа по http только на `localhost`, а пульт открыт по
голому IP — поэтому возврат идёт на `localhost` оператора, и адрес оттуда вставляется в пульт:

1. В Google Cloud того же проекта, что и календарь, включите **People API**.
2. В OAuth-клиенте (Web application) добавьте `http://localhost:8765/` в Authorized
   redirect URIs. Перекачивать JSON клиента на сервер не нужно.
3. В окне Google Контактов нажмите **«Открыть Google»**, разрешите «Просмотр контактов».
4. Google откроет `http://localhost:8765/?state=…&code=…` с ошибкой «не удаётся получить
   доступ к сайту» — это нормально. Скопируйте адрес вкладки, вставьте в поле 3, «Готово».

Сервер меняет код на токен (PKCE, `access_type=offline`), проверяет его запросом в Google
и пишет `axiom/google_contacts_token.json` (в git не попадает). Календарный доступ отдельный
и не меняется. Запасные пути: `tools/google_contacts_login.py` на своём компьютере и
загрузка файла доступа (`/api/google-contacts/token`), либо экспорт **Google CSV**
кнопкой «Загрузить Google CSV» — ярлыки читаются из колонки `Labels`/`Group Membership`.

## Изоляция и повторный импорт

Дубли сопоставляются по нормализованному телефону (`8 916…` и `+7 916…` равны).
История и поля существующей CRM-карточки сохраняются. Контакты не в статусе `new`,
тестовые, удалённые и закреплённые за другой кампанией пропускаются с причиной.
Неоднозначные дубли в существующей базе автоматически не сливаются.

Добавляемое миграцией поле `contacts.outreach_campaign_id` ограничивает выбранные
контакты одной кампанией. Кампании с пустым тегом и старые CLI-отправщики их не
подхватывают. Старые контакты с NULL продолжают отбираться как раньше.
Идущую кампанию можно выбрать только с явным подтверждением в окне (`allow_running`);
новый черновик создаётся с выключенным автозапуском. Режим «тег сегмента» (мастер)
пропускает контакты, уже закреплённые за кампанией: до новой они бы не дошли. Токены, сессии аккаунтов и настройки рассылок импорт не меняет.

## Проверки

Из `axiom/`: `python -m unittest discover -s tests -p test_google_contacts.py -v`.
Проверки работают с временной SQLite и подменённым Google API, не отправляют сообщения.
