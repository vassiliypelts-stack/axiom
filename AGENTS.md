- Боевой сервер Axiom: `http://34.12.128.70:8000/`.
- Это единственный боевой адрес для проверки и выкладки. Не использовать старые IP-адреса из заметок, не спрашивать адрес повторно.

- Перед деплоем проверять `git status`; чужие незакоммиченные изменения не добавлять и не затирать.
